Cloud Native Ayacucho Community (CNAYP) Discord Bot

A Discord bot for the Cloud Native Ayacucho Community (CNAYP), operated by Ken Esparta. It is used for educational and informational purposes only: sharing learning material, pointing to documentation, announcing the community’s meetups and study sessions, and posting upcoming cloud native events from public calendars.

The bot requests no permission to read messages and cannot read their contents. It stores no personal information. Nothing it returns is professional advice, and it grants no certification or credential.
